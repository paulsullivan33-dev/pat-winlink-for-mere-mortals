  templates       Manage message templates and HTML forms.
  account         Get and set Winlink.org account settings.
  mps             Manage message pickup stations.
  version         Print the application version.
  env             List environment variables.
  help            Print detailed help for a given command.

Options:
      --config string      Path to config file. (default "/home/hatch/.config/pat/config.json")
      --event-log string   Path to event log file. (default "/home/hatch/.local/state/pat/eventlog.json")
      --forms string       Path to forms directory. (default "/home/hatch/.local/share/pat/Standard_Forms")
      --ignore-busy        Don't wait for clear channel before connecting to a node.
  -l, --listen string      Comma-separated list of methods to listen on (e.g. ardop,telnet,ax25).
      --log string         Path to log file. The file is truncated on each startup. (default "/home/hatch/.local/state/pat/pat.log")

      --mycall string      Your callsign (winlink user).

      --radio-only         Radio Only mode (Winlink Hybrid RMS only).
